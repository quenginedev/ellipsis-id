ellipsis-id Fingerprinting Demo

This example demonstrates how to use the ellipsis-id library to generate browser fingerprints.

Click one of the buttons above to generate a fingerprint.

Implementation

// Basic usage
import { generateFingerprint } from 'ellipsis-id';

const fingerprint = await generateFingerprint();
console.log('Browser fingerprint:', fingerprint);

// Detailed usage
import { generateDetailedFingerprint } from 'ellipsis-id';

const detailedResult = await generateDetailedFingerprint();
console.log('Detailed fingerprint:', detailedResult);

// Custom configuration
import { generateFingerprint } from 'ellipsis-id';

const customFingerprint = await generateFingerprint({
  methods: ['basic', 'canvas', 'webgl'],
  hashAlgorithm: 'sha-256',
  includePublicIp: false,
  timeout: 3000
});
